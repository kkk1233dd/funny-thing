# 桌面日历小部件 - 产品需求文档

## 1. 项目概述

**项目名称**: 宫崎骏风格桌面日历小部件
**项目类型**: 桌面透明窗口小部件
**核心功能**: 嵌入桌面的日历工具，支持每日任务管理和倒计时功能
**目标用户**: 需要在桌面随手记录任务、关注重要日期的用户

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 透明桌面小部件
- 透明背景窗口，嵌入桌面
- 窗口可拖拽定位
- 置顶显示，不影响其他操作
- 右键菜单支持退出程序

#### 2.1.2 日历主体
- 显示当前月份和日期
- 农历日期显示
- 季节/节日提示

#### 2.1.3 每日任务（循环日志）
- 添加每日重复任务
- 勾选完成任务
- 任务数据存储到本地TXT
- 支持编辑和删除任务

#### 2.1.4 倒计时
- 添加倒计时事件（如：中考倒计时）
- 显示剩余天数
- 支持多个倒计时事件
- 数据存储到本地TXT

### 2.2 数据存储
- 使用 `data.json` 文件存储所有数据
- 包含任务列表和倒计时列表
- 程序启动时自动读取恢复数据

## 3. 设计规范

### 3.1 视觉风格
- **整体色调**: 浅绿色系，清新自然
- **参考风格**: 宫崎骏动画的清新、自然、温暖感
- **背景**: 半透明磨砂玻璃效果
- **装饰元素**: 轻量的植物/自然元素装饰

### 3.2 色彩方案
```
--bg-primary: #e8f5e9 (浅薄荷绿背景)
--bg-secondary: #c8e6c9 (稍深绿色)
--accent: #81c784 (主强调色-草绿)
--accent-dark: #66bb6a (深强调色)
--text-primary: #2e7d32 (深绿色文字)
--text-secondary: #558b2f (次要文字)
--border: #a5d6a7 (边框色)
--shadow: rgba(129, 199, 132, 0.3) (阴影)
```

### 3.3 字体
- 主标题: "ZCOOL XiaoWei", serif（思源宋体备选）
- 正文: "Noto Sans SC", sans-serif
- 数字: "DIN Alternate", "Helvetica Neue", sans-serif

### 3.4 布局
- 固定宽度约 320px
- 圆角卡片设计
- 内边距舒适
- 区块分明

## 4. 交互规范

### 4.1 任务管理
- 点击"+"添加新任务
- 点击任务左侧勾选框完成任务
- 双击任务文字编辑
- 滑动或点击删除按钮移除任务

### 4.2 倒计时管理
- 点击"+"添加新倒计时
- 输入事件名称和目标日期
- 显示"XX天"
- 删除按钮移除

### 4.3 窗口交互
- 可拖拽移动位置
- 右键显示系统菜单
- 关闭按钮最小化到托盘

## 5. 技术方案

### 5.1 框架选择
- **Electron**: 成熟稳定，支持透明窗口
- **纯HTML/CSS/JS**: 轻量简洁

### 5.2 文件结构
```
/workspace/
├── main.js           # Electron主进程
├── preload.js        # 预加载脚本
├── index.html        # 主页面
├── style.css         # 样式文件
├── renderer.js       # 渲染进程逻辑
├── data.json         # 数据存储
└── package.json      # 项目配置
```

### 5.3 窗口配置
- transparent: true
- frame: false (无边框窗口)
- alwaysOnTop: true
- resizable: false
- skipTaskbar: true

## 6. 验收标准

1. ✅ 窗口透明背景成功显示桌面
2. ✅ 日历显示当前日期
3. ✅ 可添加/完成/删除每日任务
4. ✅ 可添加/查看/删除倒计时
5. ✅ 重启后数据自动恢复
6. ✅ 浅绿色宫崎骏风格界面
7. ✅ 窗口可拖拽定位
