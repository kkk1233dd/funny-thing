# 宫崎骏风格桌面日历小部件

一个清新淡雅的日历桌面小部件，具有每日任务管理和倒计时功能。

## 功能特点

- **日历显示**: 显示当前日期、星期、农历日期和季节提示
- **每日任务**: 添加、完成、删除循环任务
- **倒计时**: 添加重要事件的倒计时（如中考、高考等）
- **数据持久化**: 使用 localStorage 自动保存数据，重启后自动恢复
- **宫崎骏风格**: 浅绿色磨砂玻璃效果，清新自然

## 使用方法

### 直接在浏览器中打开

1. 双击 `index.html` 文件，用浏览器打开
2. 拖拽顶部区域可以移动小部件位置
3. 点击 × 按钮可以隐藏小部件

### 设置为桌面壁纸（可选）

要在桌面上实现类似嵌入效果，可以使用以下方法：

**Windows:**
- 使用 Wallpaper Engine 或类似工具将浏览器窗口置顶

**macOS:**
- 使用 Fluid 或类似工具将网页转为桌面应用

**Linux:**
- 使用 xdotool 或类似工具设置窗口属性

## 文件结构

```
/workspace/
├── index.html     # 主页面
├── style.css      # 样式文件
├── renderer.js    # 交互逻辑
├── main.js        # Electron主进程（可选）
├── preload.js     # Electron预加载脚本（可选）
├── package.json   # 项目配置
└── data.json      # 数据存储（Electron版本）
```

## 运行 Electron 版本

如果你有 Electron 环境：

```bash
npm install
npm start
```

## 数据说明

所有数据存储在浏览器 localStorage 中：
- 任务列表
- 倒计时列表
- 窗口位置

## 设计风格

- 主色调: 浅绿色 (#e8f5e9, #c8e6c9, #81c784, #66bb6a)
- 字体: Noto Sans SC
- 效果: 磨砂玻璃、圆角卡片、柔和阴影
- 动画: 淡入、滑动、悬浮效果
